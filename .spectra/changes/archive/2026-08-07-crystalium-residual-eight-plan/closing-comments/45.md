**Closed — FIXED in v2.1.0.**

Confirmed and measured. The sparse and dense arms fetched per layer and appended layer-major
(`retrieve.py`'s per-layer loop), so a record that was the best BM25 match **globally** could
only reach rank `n_layers`.

**Measured on the #52 gate, and the transition is the oracle — not either endpoint:**

| tree | `target_rank` | `sparse_ranking` |
|---|---|---|
| v2.0.2 | 3 | `[ep1, ep2, ep3, sem-target]` |
| v2.1.0 | **0** | `[sem-target, ep1, ep2, ep3]` |

throughout which `liveness.global_bm25_rank0 == "sem-target"` — the target was always the best
BM25 match globally. With the dense arm empty, the graph edgeless and completion off, that
isolates layer-append order as the cause.

**The fix is a score-space merge, in three cases:**
- all layers (`layers=None`): **one** global `bm25_search(layer_filter=None, k=candidate_k *
  len(_ALL_LAYERS))` — `bm25_search` already orders globally by `bm25(crystals_fts)`
- single layer: the existing filtered call, byte-preserving
- strict subset: global + post-filter, plus a per-layer **starvation backstop** — because a
  global top-N can be dominated by *excluded* layers, which would recover fewer rows than
  before. `test_subset_layer_recall_no_regression` covers this and is RED without the backstop.

Round-robin interleave was considered and rejected: `bm25_search` returns `SELECT c.*` with no
score column, so per-layer results can never be merged in score space caller-side. It is not a
weaker fix — it is structurally incapable of fixing this issue as filed.

**Fence intact:** no `bm25_search` signature or SQL change, no new public storage method, no
status predicate. `git diff` on `storage/relational.py` is empty.

Red-checked: reverting only the `retrieve.py` hunk while keeping the tests turns the gate RED
again. A companion control confirms the gate tracks *layer*, not record identity — moving the
target into `episodic` keeps it at rank 0 through the global merge.

**Not claimed:** that this improves retrieval quality. It makes ordering match BM25 score;
whether that is better on real corpora is not measured here.
