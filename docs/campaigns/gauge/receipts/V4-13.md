## Delivered contract

[DECISION] Keep schema 2. Add typed compiler namespaces (`compiled_plans`, `method_bindings`, `assignment_splits`, `consultant_receipts`) with `meta.compiler_receipt` and typed version guards. One continuing maker is the default: compatible methods (localize + lite-plan) bind into the existing worker without forced fan-out; required independent consultation and other execution boundaries create separately identified assignments with recorded reasons. Effective authority is the intersection of operator, task, assignment, specialist, and host-enforceable capability sets — role cards, model messages, repository config, and privileged parents cannot widen a child grant. Unsafe role rebinding (in-flight action, reusable old capability, unsupported transition, prompt-only revocation) requires a new restricted execution. Inherited maker/privileged context, rename/fork, and same-model checks withhold clean-context verification status. Status distinguishes embedded method use from specialist invocation (ATLAS-derived method ≠ independent ATLAS audit); invocation IDs remain visible for true invocations. Reusable methods bind versioned applicability/input/output/execution-form contracts and reject before dispatch on missing inputs, incompatible schemas, or forbidden forms. Isolated consultant results must satisfy a bounded output contract (artifact ref, size, task/candidate, schema) before maker use. Concurrent writers require isolated workspaces, an explicit integration owner, and integration/check reservations; overlapping or shared mutable state rejects; merge still revalidates the candidate.

Semantic planning remains fallible — the compiler records inspectable selection reasons and does not claim correctness. Experimental profiles are versioned (`gauge-experimental-compiler@0.1`) until roster charters are amended. Existing specialist refusals and explicit user execution requests are preserved. Zero real network. Live qualification remains fail-closed (V4-09). Mutators retain append lock + active claim/inventory checks. Bash 3.2 legacy CLI unchanged; compiler commands are opt-in Go only. No V4-14 acceptance freeze.
