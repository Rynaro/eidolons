## Delivered scope

[DECISION] Keep the V4-04 journal authoritative: capture acceptance-relevant observations and inputs there, reference larger evidence by digest, and derive views. The FORGE decision selected this bounded hybrid to avoid a second acceptance database without embedding all supporting objects. A digest establishes bytes, not independent execution.

Candidate identity binds tracked and discovered/required-untracked inputs, HEAD, integration base, criteria, explicit environment/configuration, file bytes/kinds/modes, ancestor permissions and symlink traversal through resolved-target ancestry. Unsupported or missing inputs fail closed; user exclusions cannot hide acceptance inputs. The latest applicable outcome wins per complete identity tuple and check/oracle; a later failure displaces a pass. Missing/stale/cancelled/wrong-candidate/changed evidence withholds acceptance.

Artifact integrity, execution provenance and acceptance have separate typed fields. Manual/imported labels remain self-attested; absent maker or unknown context access cannot confer independent provenance. Only the pure fixture evaluator receives authenticated context in memory. Native/A2A/MCP success means termination, not acceptance. No production provenance switch or protected execution is introduced.

Canonical captures render deterministic historical JSON/text/Markdown and support saved-view drift detection with `--compare`. `augment evidence` now accepts a versioned canonical capture reference; old raw arrays, including empty arrays, fail. The [ledger reference](../../../ledger.md) documents exact examples, dependency changes, legacy retry compatibility and operational limits. Existing event bytes/declarations and unchanged legacy completion retries are preserved while derived trust is corrected.
