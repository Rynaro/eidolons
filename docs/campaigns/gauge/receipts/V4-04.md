## Delivered scope

[DECISION] Retain Bash 3.2 and existing runtime dependencies, using exclusive `mkdir` append ownership, bounded waiting and conservative recovery-required handling. Python supervision and a Python journal helper would add a runtime prerequisite and broader rewrite. The [recorded decision](../../../../.spectra/changes/gauge-v4-04/decision.md) requires evidence for child lifetime and interruption behavior before acceptance.

Exclusive ownership covers whole-prefix validation, identity/content comparison, numeric allocation, predecessor selection and publication. Optional `--event-id` makes identical caller-content retries idempotent and rejects conflicts. The 1–300 second acquisition budget defaults to 60 seconds; PID, age and absent metadata never authorize automatic lock stealing. Manual recovery requires proven quiescence of all writers and publishing children, preserving published and private pending evidence.

Inspection of unknown runs has no durable filesystem side effects. Existing schema 1.0 events remain readable without rewriting their bytes; hashing preserves the `jq -cS` payload including trailing newline. Event digests are integrity hashes, not authentication. See the [ledger guide](../../../ledger.md) for commands and recovery boundaries.
