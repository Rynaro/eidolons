## Delivered scope

[DECISION] Add a narrow opt-in Go seam under `gauge/`, using one shared controller-instance bbolt 1.5.0 database and short dependent-state transactions. The conditional FORGE decision preferred this small local transactional boundary over SQLite's additional implementation surface and a custom whole-state recovery/locking system. No Junction source was imported. Native harnesses retain reasoning and edit/test loops; no scheduler, production trust source or second filesystem candidate engine is introduced.

The [usage reference](../../../gauge.md) documents explicit binary builds/packages, the keep/shim/unsupported matrix, fixture commands, staging versus promotion, and conservative recovery. Ordinary opt-out installation and commands need no Go. Runtime never downloads or invokes a toolchain and never falls back to legacy writes.

Typed contracts distinguish durable history, context references, reusable knowledge and policy, with separate identity roles and a versioned configuration manifest. Requested settings never establish an observed model. Fixture bookkeeping invokes zero models and produces unaccepted fixture-only receipts. Imported history retains exact bytes, event identity and lower evidence grades; imported adapter provenance is `unknown`. Current-candidate acceptance and native reconstruction remain unavailable.

## Independent findings and repair

The initial maker receipt `/private/tmp/gauge-v4-06-loop/maker-receipt.md` is **pre-repair and not acceptance**. Independent review found three concrete gaps, repaired by fresh-context actor `vivi_v4_06_repair`:

1. **F001 — authority after marker loss.** A persistent per-root claim now precedes the pending marker. Either proof denies Bash writes; active Go operations bind both proofs to the shared DB, generation and frozen inventory. Explicit recovery may restore a missing marker only from matching existing authority. Invalid, missing or conflicting proofs fail closed. Unrelated roots and staged imports retain Bash writes; changed staged history blocks promotion.
2. **F002 — imported reconstruction.** Imported adapter provenance is now `unknown`; reconstruction rejects imported roots even if earlier metadata called them fixtures. Controller-created fixture roots retain positive replacement controls.
3. **F003 — repeat packaging.** Package-owned license outputs use `install -m 0644`; a non-root test sets them to 0444 between builds and verifies the rebuilt executable bytes match.

Only four production files changed in the repair: `cli/src/ledger.sh`, `gauge/internal/controller/authority.go`, `gauge/internal/controller/controller.go`, and `scripts/gauge-build.sh`. Added tests are `gauge/internal/controller/repair_test.go` and `gauge/tests/package-repeat.sh`. Original test definitions remained unchanged. `protected-tests.json` and `protected-verification.json` cover 121 frozen files, including the new regression tests frozen before source repair; verification reports no changed protected files.

Promotion tests use real independently controlled OS children, killed and reaped before the `Promote` call, after pending publication, after DB commit, and after `Promote` returns. Pending/committed cases also exercise a competing promoter and Bash writer. Recovery first refuses unresolved append ownership; tests remove their known lock only after children are reaped and the synchronous writer finishes. Reopened state retains event bytes, IDs and grades. Seven phase-15 claim probes cover lost-marker recovery and malformed/future/conflicting/missing/symlink/directory claims without DB mutation, paired with unrelated/staged legacy write controls. Full subprocess records are in `claim-probes-commands.jsonl`.

The independent re-review confirms F001–F003 and identifies a remaining coverage distinction: the `before` and `published` tests bracket the whole `Promote` call. They do not cut immediately after durable claim publication or immediately after final-marker publication before lock release. The final follow-up adds a separate `TestV406T04_PublicationWindows` and exact `claim-published` / `marker-published` callbacks while append ownership is held. Real child kill/reap, competing promoter/Bash refusal, unresolved-lock refusal, explicit recovery and preserved bytes pass twice independently. CI now invokes `package-repeat.sh` in both native matrix jobs. All 163 prior test/fixture files remain unchanged. See [final checker report](../../../../.spectra/changes/gauge-v4-06/checker-report.md) and [follow-up report](../../../../.spectra/changes/gauge-v4-06/publication-cuts-report.md).
