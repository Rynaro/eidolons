## Delivered contract

[DECISION] Keep schema 2. Add typed dispatch namespaces (`dispatch_intents`, `dispatch_events`, `dispatch_acks`, `dispatch_ops`) with `meta.dispatch_receipt` and typed version guards. Exactly one fixture-qualified host/version/mode + billing path (`codex-cli` / `0.154.0` / `local` / `exec-sandbox-readonly` / `auth-sub-1`) via `FakeNativeAdapter`. Managed dispatch sequence: V4-11 AdmitReservation → durable CommitIntent → fake Start → RecordAck. Crash/fault inject between each step. NativeMethodCounters prove no send precedes durable intent. Ambiguous outcomes reconcile via Lookup before any redispatch; unsupported lookup remains unknown (no auto-retry). Native events keep requested vs observed settings separate. Cancellation stays nonterminal until confirmed stop, distinct from final reconciliation. Cleanup is ownership-ID scoped and preserves adjacent session/process/worktree. Granularity/version/method mismatches preflight-reject; no silent privileged sibling fallback. Idempotency reuses operation identity; missing lookup/key support stays unresolved. Lost native session + portable checkpoint yields distinctly identified reconstructed invocation without claiming native-session continuity.

NativeAdapter (Start/Resume/Events/Interrupt/Lookup/Cleanup/Reconstruct) extends without breaking V4-09 HostAdapter. Transport terminal ≠ acceptance. Zero real network. Live qualification remains fail-closed (V4-09). Mutators retain append lock + active claim/inventory checks. Bash 3.2 legacy CLI unchanged; dispatch commands are opt-in Go only.
