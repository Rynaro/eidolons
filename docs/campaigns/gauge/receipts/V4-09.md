## Delivered contract

[DECISION] Keep schema 2. Add typed instrument namespaces (`capability_catalogue`, `protocol_freezes`, `attempt_records`, `eligibility_records`, `shadow_observations`, `instrument_ordering`) with `meta.instrument_receipt` and typed version guards. Catalogue tuples bind host + installed version + integration/protocol version + mode + method + effective permissions + execution boundary + granularity + maturity + evidence + permitted billing. Help/registration is discovery only.

Preflight requires current verified evidence for each required capability plus authorized billing. Credential presence is not allowance; exhausted subscription never switches to API. Drift invalidates the affected tuple; sandboxed qualification never grants a privileged sibling. Fake adapters expose transport counters covering every adapter including API; blocked paths keep all counters at zero.

Versioned protocol freezes the full field set; canonical hash includes immutable referenced manifests. Atomic freeze stores identity and append-only controller ordering before outcomes/dispatch. Caller timestamps / `approved:true` / nonempty JSON are insufficient. Shared native/original-v3 recorder schema keeps terminal execution state separate from acceptance+evidence; failed/cancelled/abandoned remain in the denominator; known/estimated/unknown costs stay distinct. Original-v3 control identity is exactly `752194ef5ceaa8cee1f5995fd0d374888696d8fc`; native is a distinct untouched control. Structural before V4-10 and managed before V4-15 remain ineligible (eligibility records, zero fabricated attempts). Shadow consumes copies/events; route inputs/prompts/model/tool settings/execution decisions stay byte-identical.
