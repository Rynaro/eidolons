## Delivered contract

[DECISION] Keep schema 2. Add typed delivery namespaces (`delivery_loops`, `delivery_checkpoints`, `delivery_obligations`, `delivery_interventions`, `delivery_events`) with `meta.delivery_receipt` and typed version guards. One maker default progresses authorized phases (admit → dispatch → edit → freeze → check → checkpoint → accepted) without routine continuation prompts; consequential product decisions are recorded interventions and remain exceptional blocks. Runnable milestones must reference an executed behavior check — stub scaffold, prose completion, and fake logs fail; genuine behavior/integration controls pass. Resource exhaustion before verification or after one slice yields nonaccepted partial progress; whole-task acceptance stays incomplete. Repeated failure with no new evidence stops within `failure_bound` using a digest stable across workers/context resets. Resume preserves root accounting, authority digest, candidate IDs, and outstanding verification; process/session/env replacement is not a new budget root. Stale/tampered/unusable-native checkpoints report exact limitations (`changed_criteria`, `tampered_payload`, `missing_native_history`, `memory_outage`) while preserving valid local/portable artifacts. Observational `delivery-inspect` exposes candidate, acceptance, pending execution, resource exposure, and next-action without model work (unknown/running/cancellation-pending/partial; FS + model-call counters). Context compact/replace keeps validated obligations and source refs independently of generated summaries; access restrictions persist. Authorized demonstrator comparison records native-control and v4 outcomes through the V4-09 instrument; missing/ineligible live arms stay explicit and never fabricated. Unresolved external effects (lost ack after effect) force resume to expose uncertainty before any dependent work.

Wires predecessors: V4-11 `AdmitReservation`, V4-12 commit/send/ack (optional fixture adapter), V4-13 assignment identity continuity, V4-14 freeze/check, V4-09 eligibility/comparison. Minimal inspect/status/resume/cancel/compact CLI+JSON now; full V4-20 deferred. Zero real network/model. Live qualification remains fail-closed. Mutators retain append lock + active claim/inventory. Bash 3.2 legacy CLI unchanged; delivery commands are opt-in Go only. No silent scope reduction, routine continue prompts, or fake background work. No V4-16+ / V4-20 / V4-21.
