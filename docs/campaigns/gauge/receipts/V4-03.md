## Delivered scope

[DECISION] Use `scripts/validate-registry.py` as the shared authored/publication gate for local `make schema`, PR, roster-health, nexus-release, and roster-intake workflows. Reject duplicate authored YAML/JSON keys before resolution, including merge-key cases; validate advertised `latest`/`stable`, explicit `PUBLISH`, and raw `RELEASE_RECORD` publication evidence. Intake checks raw manifests before normalization. The reusable member-release template remains an unchanged deterministic producer in the member checkout.

Historical evidence is preserved: the baseline contains 255 Git release records, of which two historical records are incomplete and none of the advertised records are incomplete. Explicit publication cannot use the historical allowance to publish incomplete evidence.

Wiring diagnostics and read-only preview identify managed grant/runtime/host drift. Explicit `mcp sync --repair-wiring` preserves user fields, unreceipted legacy grants, and locked local OCI identity while updating managed projections and runtime receipts. Fixtures cover Atlas-ACI hyphenated names, invoking UID:GID, spaced paths, identity mounts, and repeat generation. Codex comparison and repair require Python 3.11+ (`tomllib`).
