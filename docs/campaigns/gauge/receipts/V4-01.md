## Delivered behavior

One shared reader normalizes case and surrounding whitespace, validates the closed `strict`/`warn` set, and rejects explicit empty/invalid values, wrong types, unreadable YAML, unavailable parsers, and failed parser output. Diagnostics name the policy source without reproducing values or parser stderr; failed reads emit no mode on stdout.

Verify, doctor, sync, upgrade, cache admission, release-status recording, and self-upgrade propagate policy failure. Sync and upgrade check before roster use or cache mutation. Self-upgrade checks before fetching a replacement, including non-tag refs and `--allow-unverified`.

Strict source admission rejects empty or malformed evidence and requires a comparable source hash. Hashes remain independent: optional empty/null fields are allowed, and installed verification can validate manifest-only evidence against actual installed bytes. Strict self-upgrade no longer automatically accepts placeholder-only evidence.
