## Delivered contract

[DECISION] Keep schema 2. Add typed context namespaces (`context_sessions`, `context_evidence`, `context_memory`, `context_navigation`, `context_overhead`, `context_features`, `context_events`) with `meta.context_receipt` and typed version guards. Reuse pin IDs from `roster/pins.yaml` and zone/debounce posture from `roster/context-policy.yaml` / `cli/src/lib_context.sh` as reference constants. Evidence reuse validates source/criteria/environment dependencies (relevant mutations and missing artifacts invalidate; unrelated controls reuse only with a proven dependency). Bounded presentation returns a localized excerpt including decisive content plus a usable full reference; inaccessible/deleted references are reported. Cold/warm succession retains mandatory pins and outstanding failure/budget/check/authority obligations without fabricating unseen history. Optional memory (including CRYSTALIUM-labelled notes) continues unavailable/untrusted paths without receipt promotion or operational authority. Batched/wrapper tool ops enforce the same deny boundary as individual calls. Repeated unchanged triggers honor configured debounce/hysteresis without asserting universal thresholds. Overhead reports separate host-visible bytes, source-file bytes, and labeled token estimates (unsupported visibility noted). Scoped memory binds provenance/project/applicability/supersession/expiry; conflicts and invalid dependencies are presented before guidance (no silent newest-text-wins). Navigation distinguishes discovery, retrieval, and cited use — availability alone is not use. Atomos remains compose/verify-only. No mandatory vector store.

Zero real network/model. Live qualification remains fail-closed. Bash 3.2 legacy CLI unchanged; context commands are opt-in Go only. No V4-10/16/17/18/22.
