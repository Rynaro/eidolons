## Delivered contract

[DECISION] Persist separate `user` and `project` preference layers in the existing shared controller-instance DB, with revision compare-and-swap and canonical digests. Both are controller-local logical layers; no account/home settings, cross-project defaults or authenticated user identity are introduced. Rootless preference updates require an initialized store and never fabricate an execution root. Built-in < user < project < run determines preference precedence; authority restrictions intersect independently.

Explicit database schema 1→2 migration adds typed namespaces and a migration receipt in one DB transaction. It retains controller identity, roots, history, replay markers, legacy policy JSON and existing filesystem proofs. New ordinary opens refuse unmigrated schema 1; the real older V4-06 binary refuses schema 2. Missing receipts/namespaces or unsupported versions fail closed without automatic recreation or downgrade. Migration preserves old references without converting generic JSON into grants or active V4-07 bindings.

Policies report field provenance and keep immutable typed snapshots, bindings and amendment results. Designated authorization supplies grants before restrictions intersect; a restriction cannot create a grant. Comparable ceilings take minima while distinct scopes remain applicable. Presets change optional strategies while retaining mandatory checks, criteria, grades and authority requirements. Strategies are selections from a pinned versioned data registry, not executable adaptation.

The production compiler is **inspection-only**, with `authorizer_boundary_unqualified`. No production constructor supplies the private authorizer; genuine positive controls exist only in `_test.go`. File/env/CLI labels, authorization IDs, writer generations and DB ownership cannot authenticate policy authority. Production bind/amend requests refuse; compilation does not persist a binding. No live security, billing, provider or protected operator boundary is qualified. [Gauge usage](../../../gauge.md#v4-07-preferences-and-migration) provides exact commands and valid JSON examples.
