## Delivered contract

[DECISION] Keep schema 2. Add typed reservation namespaces (`reservations`, `scope_balances`, `reservation_events`) with `meta.reservation_receipt` and typed version guards. Atomic local admission intersects known V4-07 ceilings (task/project/account/window/concurrency) under the active PolicyBinding identity — never invents grants. Protected verification/recovery headroom is excluded from optional implementation. Observed overrun/late usage/corrections retain actual exposure (never clamped away). Unknown post-dispatch outcomes retain uncertain exposure until explicit reconcile/release-with-proof (no automatic release). Provider window reset changes window balances only; root task consumption is preserved. Authoritative accounting faults (corruption, lock timeout, full storage, read-only) reject managed admit; advisory hooks keep a separate error. Hard-limited dimensions without usable observation or authorized conservative bound reject; explicit bounded mode is the positive control. Child/retry joint-reserve implementation+integration+required verification under the parent and cannot borrow protected headroom.

No remote/provider call occurs inside a store transaction. V4-09 live admission remains fail-closed. Zero real network/transport. Mutators retain append lock + active claim/inventory checks. Bash 3.2 legacy CLI unchanged; reservation commands are opt-in Go only.
